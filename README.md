# 🌗 Mode Switcher App

A simple and responsive web app that allows users to toggle between **Light Mode** and **Dark Mode**, with their preference saved automatically.

---

## 🚀 Live Demo

👉 https://griffin-lugahi.github.io/Mode-Switcher-App/

---

## ✨ Features

* 🌞 Toggle between Light and Dark mode
* 💾 Remembers user preference using localStorage
* ⚡ Instant UI update on click
* 📱 Responsive design (works on mobile & desktop)
* 🎯 Clean and simple user interface
